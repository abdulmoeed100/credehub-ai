# Credehub AI Backend

This is the FastAPI backend for Credehub AI, built with RAG (FAISS + BM25 + BAAI/bge-small-en-v1.5 embeddings) and Groq API.

## Features
- AI-powered chat with Karachi Board Class 9 Computer Science PDF context.
- Automated MCQ Assessment generator.
- AI-generated personalized student reports.
